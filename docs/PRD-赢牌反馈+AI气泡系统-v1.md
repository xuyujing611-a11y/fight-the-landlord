## 1️⃣ 赢牌/结束牌反馈方案

### 1.1 现状

| 场景 | 现状 | 问题 |
|------|------|------|
| 玩家赢 | `setStatusText('恭喜你赢了！')` + `showToast()` 一行字，无其他反馈 | 毫无仪式感，没有分数统计 |
| AI赢 | `setStatusText('王怼怼 出完了！获胜！')` + `showToast()` | 同样简陋 |
| 无按钮 | 赢牌后无"再来一局"或"返回首页"按钮 | 玩家只能强行刷新页面 |

### 1.2 设计目标

每局结束后弹出一个全屏结算面板，包含:
- 胜负结果（带动效和颜色区分）
- 得分统计（底分、炸弹加成、搞事情加成等）
- 胜负归属（玩家/AI1/AI2）
- "再来一局"和"返回首页"按钮

#### 1.3.3 胜负判定与得分计算

| 字段 | 玩法 | 计算逻辑 |
|------|------|---------|
| 基础底分 | 玩家是地主 +30，农民 +20 | 固定值 |
| 炸弹翻倍 | 本局全场总炸弹数 | ×2/个炸弹，×4/火箭 |
| 搞事情得分 | 答对题数 | 每题 +10 |
| 手牌奖励 | 对手剩余牌数 | 每张 +2 |

**玩家赢条件：** `this.playerHand.length === 0`  
**AI1/王怼怼赢条件：** `this.ai1Hand.length === 0`  
**AI2/苏甜甜赢条件：** `this.ai2Hand.length === 0`

**得分计算公式演示：**
```
基础底分(20) + 搞事情得分(5×10=50) + 手牌奖励(对手剩10张×2=20)
= 90 分
炸弹翻倍(本局2个炸弹) → 90 × 2 = 180
总得分: +180
```

#### 1.3.4 新状态: ROUND_END

在 `GAME_STATE` 中新增或强化状态处理：

| 位置 | 玩家赢 | AI1赢 | AI2赢 |
|:----:|:------:|:-----:|:-----:|
| `confirmPlay()` | ✅ `this.playerHand.length === 0` | — | — |
| `handleAIPlay()` | — | ✅ `this.ai1Hand.length === 0` | ✅ `this.ai2Hand.length === 0` |
| `doAITurn()` | — | ✅ 未初始化处理 | ✅ 未初始化处理 |

**新增函数：`renderRoundEndPanel()`** 写在 game.js 中，负责全部结算渲染逻辑。

#### 1.3.5 进入结算的交互流程

```
触发胜出条件
    ↓
this.gameState = GAME_STATE.ROUND_END
    ↓
遮罩淡入 (0.3s, alpha 0→0.65)
    ↓
标题弹入 (0.4s, scale 0.3→1.0, ease back-out)
    ↓
得分面板整体淡入 (0.3s)
    ↓
总得分数字从0跳动到最终值 (1.2s, 每30ms一更新)
    ↓
各细项逐行淡入 (每行间隔150ms)
    ↓
按钮弹入 (延迟0.2s后两个按钮同时弹入)
    ↓
玩家可交互
```

**按钮行为：**

| 按钮 | 行为 | 代码 |
|:----:|------|------|
| 🔄 再来一局 | 重新开始当前游戏（重启场景） | `this.scene.restart()` |
| 🏠 返回首页 | 刷新页面回到加载画面/显示首页菜单 | `window.location.reload()` 或自定义主页 |

## 2️⃣ AI气泡文字系统

### 2.1 现状

目前 game.js 已有 `_showPlayBubble()` 函数（位于出牌区），功能是可以显示AI气泡，但存在以下问题：

| 问题 | 具体表现 |
|:----|---------|
| 文字太小 | 气泡文字 14px，但在960×600比例下偏小 |
| 显示时间太短 | 当前 `delayedCall(5000)`，即5秒，但需要评估是否足够 |
| 气泡位置偏低 | 出牌气泡 Y=120/150，与出牌区重叠较多 |
| 没有紧急/重要分级 | 所有气泡显示时间一律5秒，Boss炸弹等无区别 |
| 气泡无弹入动画 | 直接出现，没有过渡感 |
| 显示时有文字截断 | 部分长台词会超出气泡宽度（540px限制） |

#### 2.2.4 显示时长

| 消息类型 | 显示时长 | 适用场景 | 建议修改位置 |
|:--------:|:--------:|---------|:----------:|

#### 2.2.5 状态机（每个气泡独立）

```
showPlayBubble(aiId, event, context)
    ↓
创建气泡图形 + 文字
    ↓
弹入动画 (scale 0.8→1.0, 8帧)
    ↓
[显示中] ← 计时器开始倒计时
    ↓
计时到 → 渐隐动画 (alpha 1→0, 10帧) → 销毁对象
```

**队列系统（防止多个气泡同时显示冲突）：**

当前 `_showPlayBubble` 每次被调用时会**直接销毁旧气泡**然后创建新气泡（已有实现），这个机制继续保留，但增加一个**最小显示保障**：

```javascript
// 改进后的行为
if (当前气泡显示时间 < 1.5秒) 
   不销毁旧气泡，等旧气泡到1.5秒后再替换
else
   立即替换
```

#### 2.2.7 弹入动画实现（Phaser Tween）

```javascript
// 气泡弹入动画示例（写在 _showPlayBubble 中）
var container = scene.add.container(bubbleX, bubbleY);  // 或用单个graphics
container.setScale(0.8);
container.setAlpha(0);

scene.tweens.add({
  targets: container,
  scale: 1.0,
  alpha: 1.0,
  duration: 150,        // ~8帧(60fps)
  ease: 'Back.easeOut',
  onComplete: function() {
    // 渐隐动画（在delayedCall触发时执行）
    scene.time.delayedCall(displayFrames, function() {
      scene.tweens.add({
        targets: container,
        alpha: 0,
        duration: 200,   // ~12帧
        ease: 'Linear',
        onComplete: function() {
          container.destroy();
        }
      });
    });
  }
});
```
